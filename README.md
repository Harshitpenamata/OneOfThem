# One of Them

Previz for the short film *One of Them*, made in Unreal Engine 5.8 (24 fps, 2.39:1).

This repository holds the film's own work: sequences, dialogue, scripts and tools.
It won't open as a complete project on its own. Left out on purpose:

- Third-party asset packs (characters, animation, environments, the car model)
- Sound effects, music, sound mixes and rendered movies
- Reference images
- Generated folders (`Saved`, `Intermediate`, `DerivedDataCache`, `Binaries`) and plugins

Binary files use Git LFS.
